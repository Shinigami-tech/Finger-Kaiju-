# Finger Kaiju

Mixed reality, hands-only game for Meta Quest. Your real desk becomes a tiny city and your hand becomes a giant monster.

Built with the [Immersive Web SDK](https://github.com/facebook/immersive-web-sdk) (WebXR + Three.js) for the Meta VR Start Developer Competition 2026.

## Run locally

Requires Node.js 20.19+ (or 22.12+ / 24+).

```bash
npm install
npm run dev
```

The dev server opens the app in your browser with the built-in WebXR emulator (Meta Quest 3, hand tracking).

## Build

```bash
npm run build
```

Output is written to `dist/`.
